# Методология работы

Общие подходы для всех профилей. Перенесено из legacy default-profile AGENTS.md.

## 1. SuperMemory как старт
При начале новой сессии или вопросе "что делали" — первым делом `knowledge_recall` / `supermemory` для загрузки persistent memory. Не гадать, не переспрашивать.
- **Query** — по теме задачи, не абстрактно
- **Когда**: старт сессии, перед сложной задачей, вопрос о контексте
- **Зачем**: не повторять пройденное, не терять найденные решения

## 2. Compress по вехам
После завершения substantive задачи — компрессия диапазона сообщений через `compress`.
- **Что сжимать**: tool output'ы, неудачные попытки, back-and-forth уточнения
- **Что НЕ сжимать**: активную задачу, открытые вопросы
- **Триггер**: имплементация готова, аудит проведён, пользователь сказал "поехали дальше"
- **Зачем**: экономия токенов, продление жизни контекста

## 3. Профиль как живой документ
Рефлексия после сессии — переносить повторяющиеся паттерны в AGENTS.md.
- **Фиксировать**: HOW (как делаем), не WHAT (что сделали)
- **Только общее**: без имён проектов, доменов, конкретных credentials
- **Только проверенное**: не гадать, не обещать
- **Триггер**: нашли новый подход, ограничение инструмента, repeatable workflow

## 4. Multi-model split
Разделение анализа между моделями с разным контекстом.
1. **Большая модель (262K)** — весь код целиком: архитектура, общий анализ
2. **Малая модель (16K)** — дробные чанки <500 токенов: детальный поиск багов
3. **Cross-check** — сверить результаты, отсеять false positives
- **Когда**: security-аудит, high-stakes code review, работа с разно-квантизированными моделями
