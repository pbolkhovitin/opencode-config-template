# Governance — языковые инструкции профиля dev

Бывший `docs/fullstack/GOVERNANCE.md`, перенесён в `dev` после слияния профилей.

## Добавление нового языка

1. Создай `profiles/dev/instructions/<lang>.md` по шаблону:
   - toolchain и версии
   - команды (build, test, lint, format)
   - конвенции
   - блок проверки версии
2. Добавь `<lang>.md` в `instructions: [...]` в `profiles/dev/opencode.jsonc`.
3. Обнови таблицу языков в `docs/dev/README.md` и `profiles/dev/AGENTS.md`.
4. Добавь шаги установки в `setup.sh`, если нужны новые CLI.
5. Прогони `bash tests/run.sh`.

## Изменение инструкций

- Ломающие изменения (смена toolchain, разворот конвенций) — отдельным коммитом с пояснением.
- Мелкие правки (новая команда, версия) — можно вместе с профилем.
- Каждое изменение должно проходить schema-валидатор и pytest.

## Ревью

- Изменения в `profiles/dev/` проходят ревью (человек или `@code-reviewer`).
- Языковые линтеры должны проходить до merge.
- Для кросс-языковых изменений используй `@code-reviewer`.

## Версионирование

Профиль следует SemVer-совместимой схеме: `0.x` — развитие, `1.0.0` — стабилизация набора
языков и инструкций.
