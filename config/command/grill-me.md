Активируй скилл `grill-me` для плана: $ARGUMENTS

Выполни полный цикл:
1. Если указан путь к файлу плана — сначала прочитай его.
2. Запусти извлечение веток решений:
   `python3 ~/.config/opencode/skills/grill-me/scripts/decision_tree_extractor.py <path>`
3. Сгенерируй вопросы с рекомендованными ответами:
   `python3 ~/.config/opencode/skills/grill-me/scripts/question_generator.py <path>`
4. Стартуй сессию:
   `python3 ~/.config/opencode/skills/grill-me/scripts/grill_session_tracker.py --action start --session <name> --plan <path>`
5. Веди интервью: один вопрос за ход, каждый — с рекомендованным ответом и обоснованием. Если вопрос можно разрешить поиском по коду — сначала исследуй код.
6. Фиксируй ответы: `--action record --question-id N --answer "..."`.
7. По завершении всех веток закрой сессию и выдай сводку «decisions locked».

Строгие правила: один вопрос за ход, никогда не пакетируй; каждый вопрос — с твоей рекомендацией (не «что думаешь?»); сначала исследуй код/кодбазу, потом спрашивай; иди по дереву решений в глубину; зависимости решай до зависимых решений.
