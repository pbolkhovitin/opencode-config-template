# Design Toolkit

Скилл для задач «сделай красиво и проверь глазами»: лендинг, дашборд, админка,
UI-кит, оформление документа или презентации.

Каталог инструментов (что подключено, что можно добавить) —
`docs/design-toolkit.md` в репозитории конфигурации.

## Порядок

1. **Определи жанр и ограничения.** Тип экрана (маркетинг / продукт / данные),
   аудитория, тон, стек (Next.js? статика? Tailwind/shadcn?). Зафиксируй 1–2
   референса как «приём», а не как объект копирования.
2. **Арт-дирекшн одной страницей.** Палитра (oklch/hex), типо-пара, плотность,
   радиусы, тени, motion, брейкпоинты. Без этого шага не писать CSS.
3. **Токены до компонентов.** CSS-переменные или Tailwind theme:
   `--background/--foreground/--muted/--border/--accent/--destructive`,
   spacing по 4px, `--radius`, `--shadow-*`, `--duration`.
4. **Каркас.** Сетка, иерархия (один H1), зоны внимания, состояния
   loading/empty/error, скелетоны.
5. **Компоненты.** Сначала `shadcn` MCP: поиск в реестре и установка, только
   потом ручной код. Иконки — один набор, один stroke.
6. **Приёмка.** `npm run dev` → скриншоты 390/768/1440 через `chrome-devtools` →
   чек-лист ниже. Для сценариев («открыть меню, отправить форму») — `playwright`.

## Чек-лист приёмки

- Нет горизонтального скролла и обрезанного текста на 320–1440.
- Контраст: текст ≥ 4.5:1, крупный ≥ 3:1, границы UI ≥ 3:1.
- Видимый `:focus-visible` на всех интерактивных элементах.
- Клавиатура: Tab-порядок логичен, Esc закрывает оверлеи, ловушка фокуса в модалках.
- `prefers-reduced-motion` отключает анимации.
- Длинный контент: 100+ символов в заголовке, длинное слово, 0 элементов в списке.
- Консоль без ошибок, ассеты без 404, нет layout shift.
- Один акцентный цвет, одна шкала радиусов, один набор теней.

## Инструменты

| Задача | Инструмент |
|---|---|
| Скриншот, DOM, контраст, ошибки консоли | MCP `chrome-devtools` |
| Сценарий с кликами, регрессия формы | MCP `playwright` |
| Компоненты из реестра | MCP `shadcn` (`shadcn@latest mcp`) |
| Схемы и потоки в доках | MCP `mermaid` |
| Иллюстрации, фоны, мокапы | `image_generate` (плагин `opencode-gpt-imagegen`, Codex OAuth) |
| Аудит a11y | скилл `accessibility-a11y` |
| Проверка e2e | скилл `webapp-testing` |

## Если чего-то не хватает

- **Figma-макет** — нужен `FIGMA_API_KEY` (профиль `design`, сервер `figma`
  выключен) или MCP `figma-developer-mcp` / `GLips/Figma-Context-MCP`. Без токена
  источник истины — код и токены в нём.
- **Penpot** — `penpot/penpot-mcp` (self-host).
- **Готовые компоненты** — `@21st-dev/magic` (ключ), `shadcn` MCP (без ключа).
- **Диаграммы-канвас** — Excalidraw / draw.io MCP (MCP Apps, проверять поддержку
  клиентом), `mcp-mermaid` как безопасный минимум.
- **3D** — `mcp-for-blender`.
- **Иконки/логотипы** — Iconify MCP, `thesvg`, `dashboard-icons`.
- **Стоковые фото** — `unsplash-mcp-server` (ключ).

Не подключай сервер «на всякий случай»: каждый активный MCP съедает контекст
своими описаниями инструментов. Добавляй выключенным (`disabled: true`) и
включай под задачу либо скрывай через `/mcp`.
