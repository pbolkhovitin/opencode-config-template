# Core Instructions

Общие правила для профиля dev (бывший fullstack).

## Обязательства
- Код — на английском, сообщения/комментарии — на русском
- Перед билдом: проверь типы
- Перед коммитом: запусти тесты
- При изменении инструкций: обнови CHANGELOG
- Используй opencode-supermemory для сохранения контекста

## MCP инструменты
- filesystem — основное средство работы с файлами
- docker — для изолированного билда/тестов (не ставь тулчейны на хост)
- ssh — удалённые серверы и деплой
- postgres — базы данных
- playwright — E2E-тесты
- duckduckgo — поиск документации
- github — PR, issues, ревью

## Работа с агентами
- `/code-architect` — для архитектурных решений и плана
- `/code-reviewer` — для ревью кода
- `/platform-engineer` — для инфраструктурных задач

## Безопасность sudo
- **Никогда** не используй `sudo -S` (пароль через stdin) и не проси пароль в чате
- Сначала `sudo -n <cmd>`; если нужен пароль — попроси пользователя выполнить `sudo -v` в своём терминале и дождись подтверждения
- Bash-инструмент агента работает без управляющего терминала, поэтому askpass (`sudo -A`) там не работает
- `sudo -n` не печатает пароль и не отправляет его в LLM
