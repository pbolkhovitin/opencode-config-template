# Участие в проекте

Спасибо за интерес. Это шаблон конфигурации OpenCode, и он живёт за счёт
исправлений документации, скриптов и тестов.

## Что приветствуется

- исправления ошибок в `setup.sh`, `setup.ps1`, `scripts/` и `tests/`;
- актуализация документации и примеров;
- улучшения CI и проверок;
- новые скиллы и агенты, если они не привязаны к конкретной организации;
- сообщения о неработающих ссылках, устаревших командах и опечатках.

## Что не принимается

- личные конфигурации, токены, пароли, внутренние адреса и домены;
- данные работодателя, клиентов и инфраструктуры;
- изменения, ломающие default-профиль или публичную обезличенность;
- массовые переименования без функциональной причины.

## Как предложить изменение

1. Сделайте fork и отдельную ветку:

   ```bash
   git checkout -b fix/short-description
   ```

2. Внесите изменение и проверьте его:

   ```bash
   python3 tests/validate_configs.py config profiles
   python3 -m pytest tests -q
   ```

3. Убедитесь, что в диффе нет секретов и личных путей:

   ```bash
   git diff
   ```

4. Откройте pull request по шаблону. Опишите проблему, решение и способ
   проверки.

## Стиль

- Документация и сообщения пользователю — по-русски; код, имена, комментарии
  в коде и заголовки коммитов — по-английски.
- Коммиты — Conventional Commits: `fix(setup): ...`, `docs(wsl): ...`,
  `test(project-init): ...`.
- Один PR — одна логическая правка.
- Новое поведение сопровождается тестом в `tests/`.

## Публичная сборка

Репозиторий — обезличенная сборка приватной конфигурации. Если правка должна
сохраниться после следующего экспорта, отметьте это в PR: мейнтейнер перенесёт
её в исходный репозиторий и пересоберёт шаблон. Прямые правки сгенерированных
файлов могут быть перезаписаны.

## Кодекс поведения

Проект следует [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Будьте уважительны; непубликуйте чужие персональные данные и секреты.
